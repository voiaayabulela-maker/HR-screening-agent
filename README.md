# AI HR Screening Agent 🤖

## Project Overview
This is an AI-powered HR screening system that evaluates CVs against job descriptions, calculates a match score, and generates interview questions.

## Features
- CV and Job Description input
- Skill matching system
- Candidate scoring
- Shortlist / Review / Reject decision
- Explanation of matches (WHY matched)
- Interview question generator
- Simple Gradio UI

## How it works
CV + Job Description → Skill Matching → Scoring → Decision → Interview Questions

## Tech Stack
- Python
- Gradio
- Rule-based AI logic
